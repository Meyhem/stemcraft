Every numeral is mono and tabular

Bars, BPM, tempo percentage, semitones, timecode, durations, file sizes. Proportional digits shift width as they change, which makes a live readout visibly wobble next to a moving playhead. font-variant-numeric: tabular-nums is applied by the .num class and is not optional.

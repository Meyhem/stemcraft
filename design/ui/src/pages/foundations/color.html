Color

One rule holds the system together: saturation carries meaning. Muted hues identify a stem and appear only where a stem is named. Vivid hues are system signals and appear only in chrome — banners, job rows, device badges. The two sets never share a context, so a vivid red on screen always means something failed, never drums.

Stem identity — muted

vocals--ds-vocals · #E0A458
drums--ds-drums · #D9605F
bass--ds-bass · #4FC3B0
other--ds-other · #8E85E0

Amber and coral are not safely separable under deuteranopia. Stem identity therefore never rests on hue alone: fixed order (vocals, drums, bass, other), always labelled, always the same lane position. Hue is an accelerator, not the carrier.

Transport bar

The only strip you look at while playing, so it holds only what a hand with an instrument in it reaches for. One row: play, the bar and chord readout, tempo and pitch, loop, practice. Tempo and pitch are steppers, not sliders — tempo moves in 10% steps (↑/↓ still move 5%), pitch in semitones — so each is a pair of 56 px buttons and a readable number rather than a knob you have to land. Everything set once per session — loop bars, saved loops, metronome, count-in — sits one click away in a popover, never on the bar itself.

Keyboard

Every performance control has a key, because reaching for a mouse mid-song is the thing this layout is trying to avoid. Space play/pause · L arm loop · A/B set the loop start / end to the current bar · M metronome · 1–4 mute stem by lane position · ↑/↓ tempo ±5% (the buttons step 10%) · ←/→ jump one bar. Esc closes an open popover.

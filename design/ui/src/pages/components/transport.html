Transport bar

The only strip you look at while playing, so it holds only what a hand with an instrument in it reaches for. Row 1 is what you press: play, the bar and chord readout, loop, practice. Row 2 is what you adjust: tempo as a wide slider, so 88% versus 90% needs no precision, and pitch as a stepper — it is only ever a whole number of semitones, so − and + beat dragging a knob. Both are 56 px targets. Everything set once per session — loop bars, saved loops, metronome, count-in — sits one click away in a popover, never on the bar itself.

Keyboard

Every performance control has a key, because reaching for a mouse mid-song is the thing this layout is trying to avoid. Space play/pause · L arm loop · A/B set the loop start / end to the current bar · M metronome · 1–4 mute stem by lane position · ↑/↓ tempo ±5% · ←/→ jump one bar. Esc closes an open popover.

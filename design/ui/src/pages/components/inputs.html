Sliders

Sliders are for continuous values set with both hands free: per-stem gain, setup tier. Tempo and pitch used to be sliders and are now steppers — a stepped value is quicker to hit than a knob is to land. Every slider value is mirrored as a mono readout, because a knob position is unreadable at 1.5 m and a number is not.

Feedback & failure

N-08 is a design requirement, not a logging preference: prefer failing loudly and visibly over degrading silently. Every failure surface here shows the real message from the real tool — ffmpeg's stderr, yt-dlp's stderr, the Python traceback. No surface in this app paraphrases an error, and none of them offers a cheerful fallback.

Everything that loads says so with a small cousin of the navbar pulse bar: the four stem glows pounding to a made-up 120 bpm groove. Page stands in for a whole screen's content (song, album, export, library, jobs, theory); inline sits where one component is still coming. The label is always shown and is what a screen reader hears; the strip is decoration. Under reduced motion it holds one still frame rather than vanishing, because a loader that disappears reads as "finished".

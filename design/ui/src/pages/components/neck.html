Neck & theory controls

The Theory tab draws every board with one Neck component: any instrument and tuning, any fret window, labels by note, interval or degree. The highest string is on top, as a player looks down at it. The root takes the bass hue, matching the Scale sheet. Everything the player acts on (the dot to play now, a question, a lit picker) is accent, because a lit control is chrome (U-01). Right and wrong in a quiz are the vivid ok and error signals.

Labels: note · interval · none

Instruments and tunings

Open strings sit in their own column left of the nut, so an open note never shares a spot with fret 1. String names are drawn from the tuning, so drop D reads D on the low string.

Position window

One position (a box the hand covers without shifting) is outlined in the accent; notes outside it drop to 28 %. They stay visible so the player sees where the box sits on the neck.

Zoomed window · voicing cards

When the nut isn't in view, the first fret is numbered. A muted string is a ✕ in the open column or at the window's left edge.

Weak-spot heatmap

Each cell is shaded from the last 5 answers at that position: error for weak, ok for strong, fainter the closer to the middle. Positions never asked stay blank. It's calculated from the quiz history and never stored.

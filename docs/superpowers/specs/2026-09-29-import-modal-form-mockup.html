Import as a modal

One form, one source zone. You give it a file or a link, whichever came last wins. After you submit, the same modal shows the five pipeline steps, each derived from the song's files and jobs. Built only from existing tokens and components.

1 · Empty, opened over the Library

"New Song" or the nav link opens /import on top of the current page. Esc, ✕, Cancel or a click on the scrim closes it.

2 · A file is chosen

The zone collapses to a single row for the file. "Replace" brings the zone back, and choosing a file clears any link. Title is optional: left blank, the server fills it from the file's tags.

4 · Submitted, pipeline running

The form is swapped for the song and its five steps. Each step's state is derived from files and jobs, never stored. Closing the modal doesn't stop the work, and the Library card keeps tracking it. When step 5 is done, the primary button becomes "Open song".

Differences from the existing mockup

  • The Upload | URL toggle is gone. A single source zone takes either a file or a link.
  • Title and artist aren't filled in on the client. The server reads the tags on upload, so the fields show a "From the file's tags" placeholder. No client-side tag probe is added.
  • Pipeline steps appear only after submit, not as a preview under the form.
